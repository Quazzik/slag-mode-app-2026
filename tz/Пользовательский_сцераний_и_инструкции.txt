Пользовательские сценарии:
1. Авторизация
Заполнить поля на странице авторизации, нажать кнопку "Войти".
На вкладке авторизации вертикально расположены поля для логина и пароля, кнопка "Вход".
Вызвать метод Login, передать в него данные для аутентификации UserAuthorisationData

2. Расчёт
Выбрать необходимые шихтовые компоненты и указать их расход, затем нажать на кнопку "Рассчитать".
Поля для ввода всех параметров, необходимых для расчёта, кроме шихтовых компонентов. После полей для общих параметров, показывать карточки компонентов в сетке, ширина 3 блока. В верхней части каждого блока название компонента и его расход (вводится пользователем), ниже его параметры, их можно изменять. В верхнем правом углу блока чекбокс, он определяет, используется ли этот компонент и доступны ли для редактирования его поля с параметрами.
Вызвать метод Calculate, передать в него InputKal

3. Повторить старый расчёт
Найти нужный расчёт в блоке в правой части экрана, выбрать его и нажать на кнопку "Загрузить", затем нажать на кнопку "Рассчитать".
В правой четвери экрана небольшое окно со сккроллбаром. Оно выводит сохранённое название варианта. При нажатии на кнопку "Загрузить", заполнить все поля соответствующими значениями. Метод GetAllInputsForUserAsync и так возвращает полные параметры, так что можно даже не обращаться к серверу.
Вызвать метод Calculate, передать в него InputKal


4. Удалить старый расчёт
Найти нужный расчёт в блоке в правой части экрана, выбрать его и нажать на кнопку "Удалить", подтвердить удаление 
В правой четвери экрана небольшое окно со сккроллбаром. Оно выводит сохранённое название варианта. При нажатии на кнопку "Удалить" вывести окно с подтверждением удаления.
Если пользователь подтвердил удаление, вызвать DeleteOldInputAsync, передать в него ID расчёта

5. Сохранить входные данные расчёта
Заполнить все данные, необходимые для расчёта, нажать на кнопку "Сохранить", указать название расчёта в появившемся окне
Рядом с кнопкой "Рассчитать" находится кнопка "Сохранить", при нажатии на неё, открыть модальное окно, на нём поле "Название расчёта" и кнока "Сохранить".
вызвать метод AddInputAsync, передать в него CalcDTO

6. Отредактировать/удалить/добаить справочный элемент
Перейти во вкладку "Справочники":
Редактирование: изменить элемент и нажать на кнопку "Сохранить"
