в папке tz находится пользовательский сценарий для использования сервиса и описание апи из swagger. Напиши фронтенд для этого сервиса и реализуй весь описанный в txt файле функционал.
Сделай отдельную страницу авторизации на которую перенаправляет пользователя если он не авторизован и пытается зайти на любую другую страницу.
Сделай отдельную страницу со справочниками: на странице кнопки, по нажатию на которые открывается модальное окно в котором выводится содержимое справочника, кнопка "добавить элемент" и у каждого элемента кнопки для редактирования (синий карандаш) и удаления (красная мусорная корзина).
На главной странице:
1. для выбора элементов справочников сделай выпадающий список и выводи в нём название.
2. добавление шихтовых компонентов: сделай отдельную кнопку "добавить компонент", при нажатии добавляй на странице карточку на которой выводи состав (по три элемента по горизонтали), выведи название компонента и расход в самом верхнем столбце. Все значения в карточке шихтовых компонентов должны быть доступны для редактирования. Сделай крестик для удаления шихтового компонента если пользователь передумал.
3. справа от полей ввода сделай пространство в котором будут выводится старые расчёты доступные пользователю: выводи их в формате карточек, а при наведении открывай tooltip в котором будет выведена вся информация. Структуру этого тултипа определи в отдельном компоненте.
4. при нажатии на карточку какого-то расчёта из истории подсвети снизу две кнопки - загрузить и удалить. При нажатии на удаление, удаляй этот элемент запросом к апи, при нажатии на загрузку - заполняй поля на форме ввода в соответствии с записью из истории.
5. не загружай историю при каждой прогрузке страницы - сделай отдельную кнопку "загрузить историю", при нажатии на которую ты будешь получать данные. Иначе ведь будет высокая нагрузка с возможно ненужным функционалом.
6. сделай отдельный json файл и подготовь в нём поля для заполнения, я их заполню сам. При загрузке страницы, заполни поля формы ввода данными из этого json

Внимание: не забывай про настройку роутинга и выводи все повторяющиеся блоки кода в отдельные компоненты.
